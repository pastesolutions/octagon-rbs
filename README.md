# СБР — Сервис бронирования ресурсов

Вёрстка по макету Figma «Сервис бронирования ресурсов (вариант 1)» на Nuxt 4.

**GitHub Pages:** https://pastesolutions.github.io/octagon-rbs/

## Требования

- Node.js 22.22.3+, 24.15+ или 26+
- npm 10+

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run generate   # статическая сборка в .output/public
```
